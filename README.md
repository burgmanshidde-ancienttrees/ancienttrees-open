# open.ancienttrees.app

The address the website's "Open in app" button points at. An iOS universal link opens the app only when tapped on a different domain than the page it sits on, so ancienttrees.app links here. Without the app, /open forwards to the App Store. Everything else goes to ancienttrees.app. Lives with the main repo's CONVENTIONS.md entry "Open in app from the website" (2026-10-19).
